# 版本记录

## 未发布

- DSH 设置 → Workbench 新增「窗口 → 打开方式」，可在「当前窗口」和「浮动窗口」之间切换。浮动模式把工作台作为 `position: fixed` 浮层留在 DSH 页面上，DSH 对话和侧栏仍然露在外面；支持拖动标题栏移动、八向缩放。全屏按钮和双击标题栏调用 Fullscreen API，让工作台独占系统屏幕并隐藏 DSH，可用 `Esc`、`F11` 或 macOS 的 `Ctrl+Command+F` 退出；宿主拒绝全屏时回退为原来的窗口内最大化。几何、内嵌最大化状态和打开方式都写入 `localStorage`，设置里的「重置位置与大小」可以恢复默认几何。它不是新的系统窗口，浮层内部也不再重复显示 DSH 对话栏。

## 0.2.7

- 放宽安装版本下限：`engines.dsh` 从 `^0.2.1-rc.5` 改为 `^0.2.1-rc.1`，`0.2.1` 的 rc 版本和 `0.2.2` 全系的 Harness 都不再被安装闸门拒绝。这个下限是实测出来的：在 `0.2.1-rc.1`、`0.2.1-rc.2` 上用全新 HOME 装 0.2.6 的包，工作台、官方终端和浏览器都能正常打开；退到 `0.2.1-alpha.2` 时客户端能加载、侧栏入口也在，但主面板打不开工作台，所以没有继续下探。
- 资源管理器右键新增「复制相对路径」「复制绝对路径」，文件和文件夹都可以复制，Windows 工作区会跟随根目录使用反斜杠。
- README 头部的插件图标换成动态 GIF，空编辑器首页也换成同一套新图标，原来的霓虹风格 SVG 删除。
- 左侧活动栏移除浏览器入口。网页链接和 HTML 文件改为按设置里的「默认浏览器」打开：内置浏览器复用官方浏览器标签，系统浏览器交给系统处理；HTML 通过带随机令牌的 localhost 静态服务加载，相对样式、脚本和图片都能正常解析。
- DSH 设置 → Workbench 新增「浏览器」分组，可在内置浏览器和系统浏览器之间切换；工作台没有打开时，这个设置页也不会再是空白。
- 修复浏览器标签激活时打开 DSH 设置，被浏览器页面盖住设置对话框、工作台布局错位的问题；设置打开期间浏览器页先退回侧栏，关闭设置后自动恢复。

## 0.2.6

修复工作台左上角真实鼠标点击无响应：DSH 宿主在窗口左上角铺了一块 `-webkit-app-region: drag` 的拖拽区，落在这块区域里的真实鼠标按下事件到不了页面，浏览器标签的关闭按钮、活动栏顶部的工作区图标和侧栏头部按钮可能点了没反应（注入式事件不受影响，所以自动化测试一直是绿的）。工作台整层改为 `no-drag`，标题栏仍保留窗口拖动。同时修复：新建工作区主按钮悬停时文字变白不可见；终端在 DSH 重启后残留已失效的终端 ID；从 DSH 返回工作台时标签正文空白；浏览器 store 尚未接入时关闭兜底；活动栏手抖拖拽吞掉点击。

## 0.2.5

工作台终端改用 Harness 官方终端服务，保留底部面板、右侧终端列表、重命名、分屏、拖拽尺寸和快捷键；终端按 Session 保存，折叠面板、切换工作区或刷新后保留进程，只有显式关闭才结束。新增普通浏览器标签，复用官方浏览器页面在中间标签区打开，文件与网页来回切换时保留页面状态。移除自建的终端服务与 `node-pty` 依赖，安装时不再需要本机原生模块构建环境；旧版终端进程不能迁移，升级后需要新建终端。此版本包含 0.2.4 的全部改动。

## 0.2.4

修复 Windows 上的语言服务器检测：不再把任意无扩展名文件当作可执行文件，Windows 只探测 `.exe`、`.cmd`、`.bat`、`.com`；Homebrew 和 `/usr/bin` 等 POSIX 目录不再加入 Windows 的搜索路径。Windows CI 恢复通过，此版本包含 0.2.3 的全部改动。

## 0.2.3

工作区切换窗口改为覆盖整个 DSH 窗口，背景统一模糊，不再把右侧 DSH 面板单独留下或高亮；移除工作台中重复的「显示或隐藏 DSH 侧边栏」按钮，侧边栏开关仍使用 DSH 原生入口。README 精简为快速了解与安装入口，架构适配、安装升级和版本记录拆分到 `docs/`，演示截图全部更新为浅色主题。此版本包含 0.2.2 的全部改动。

## 0.2.2

新增 AI 提交信息生成：源代码管理会根据当前变更生成 Conventional Commits 风格的提交信息，支持简洁、标准、详细三种详细程度，以及跟随最近提交、中文、English 三种语言选择，生成后仍可编辑再提交。设置面板改为左侧分类、右侧分组的布局，新增纯白与护眼主题，护眼主题同步覆盖工作台、Monaco、终端和右侧 DSH 对话栏；工作区切换窗口同步采用相同的圆角、毛玻璃背景和更宽松的尺寸。Markdown 默认打开预览，并可在“布局”设置中改为源码；活动栏支持自由拖动排序，工作区切换固定顶部；语言智能区分语言运行时与 LSP 两个安装阶段，未安装语言时不再提供无效的 LSP 操作；并排差异视图将滚动交给 Monaco，修复拖拽或滚动时界面抖动。

## 0.2.1

修复会话尚未发布时终端请求失败的问题，切换工作区会等待会话就绪并自动重试；收紧窄窗口下 DSH 对话栏、输入区和状态栏的对齐，并让工作台与 macOS 标题栏留白一致。Monaco 的转到定义改为触发官方命令，macOS 上的 Ctrl+点击现在可以跨文件跳转。界面进一步对齐 VS Code：活动栏图标增大并统一居中，标签栏改为无分隔线的圆弧标签，资源管理器行高与图标放大，空编辑器加入 DSH 鲸鱼标识。

## 0.2.0

新增语言智能：可在设置里按语言安装语言服务器（TypeScript / JavaScript 随插件提供、可在设置中启用，Python Pyright、PHP Intelephense、Shell、YAML / JSON / CSS / HTML、Dockerfile 可一键安装，Go gopls、Rust rust-analyzer、C / C++ clangd、Java Eclipse JDT LS、C# csharp-ls、LuaLS 需手动安装），提供转到定义、查找引用、Peek 多结果、智能补全、签名帮助与诊断；打开未安装语言的文件不再弹窗，需要时从工作台设置里安装。编辑器现在可直接预览 PDF、Word（LibreOffice 转 PDF）、Excel（工作表页签）和 PowerPoint；资源管理器支持拖动移动条目、拖到桌面或其他应用导出、拖到编辑器打开，Git 更改里的可预览文档会直接打开预览；选中代码或文件可一键添加到 DSH 对话。活动栏支持拖动排序和右键隐藏/恢复视图；新增居中的工作区切换窗口，可新建工作区、进入已有工作区并在同一工作区内切换会话，切换会话不再重载文件管理器。文件监听排除项改为自动读取 `.gitignore`；启动时会话尚未就绪不再显示错误；浅色终端改用 VS Code Light ANSI 色板；Git 更改列表使用资源管理器同款彩色图标，Git 图谱改为 VS Code 风格的圆角连线与节点。

## 0.1.15

统一深色主题配色：活动栏、侧栏、标签栏、底部面板和状态栏统一为 `#191a1b`，编辑器为 `#121314`，输入框与浮层为 `#202122` / `#252526`，文本和强调色同步到同一套 VS Code 风格色板（`#bfbfbf` / `#8c8c8c` / `#6e6e6e`、`#307e9f`）；Monaco 与终端使用相同底色，深色状态栏不再单独使用蓝色背景。浅色主题同步 VS Code Light：侧栏和终端为 `#f9fafb`、编辑器为 `#fff`、分隔线为 `#e5e5e5`，并为侧栏与编辑器、编辑器与终端之间加入分隔线和 8px 圆角。「跟随 DSH」模式按 DSH 的明暗切换使用与「深色」「浅色」相同的色板，因此跟随 DSH 的深色外观与右侧「深色」完全一致。设置中新增「编辑器字体大小」（11–20px），只作用于右侧打开文件的 Monaco 编辑器，拖动时防抖提交，不再让整个工作台重新排版。活动栏图标统一为 18px，选中态改为 VS Code 的圆角背景并去掉左侧蓝条；左侧活动栏增加边框和左侧上下 8px 圆角，仍然贴满窗口左边；标签栏改为 VS Code 的顶部圆角活动标签并收紧到 33px，支持鼠标中键关闭；活动标签顶部圆角加大到 8px；标签栏底线只在非活动区域显示，活动标签直接与编辑器连通。资源管理器右侧、编辑器组、终端和 DSH 对话栏改为圆角卡片，间隙使用独立的 gutter 底色，卡片底部直接贴住状态栏。列表恢复整行方角，输入框、菜单和终端按 VS Code 的圆角尺寸调整；终端标签侧栏与终端主区统一使用相同底色，终端画布背景会读取面板的实际底色（浅色下为面板灰，而不是纯白）。侧栏头、标签栏、编辑工具栏和面板头统一为 35px，文件/搜索结果/Git/终端列表行统一为 22px，输入框高度对齐 VS Code，滚动条改为 VS Code 风格的圆角滑块；编辑器组、标签栏和终端补齐顶部/底部细线，活动栏隐藏多余滚动条。资源管理器、编辑器组、终端和 DSH 对话栏统一 4px 上下留白和外边框，资源管理器补齐上下边线；中间的编辑器与终端合并为一张连续卡片，左右边框不断开，只在最外层保留圆角；终端面板关闭时编辑器卡片会自动补全底部圆角。所有卡片顶部直接贴住标题栏，不再保留 4px 上缝隙；未打开文件时隐藏空标签栏，空编辑区与编辑器背景一致；终端作为独立圆角卡片，与编辑器之间保留 4px 空隙。左右分隔条统一为 4px 指示线；将资源管理器或 DSH 对话栏拖到最小宽度以下会自动隐藏，可通过活动栏对应图标恢复。搜索结果点击后会打开对应文件、跳到匹配行并在编辑器中高亮匹配词；Markdown 文件会自动切到源码视图。源代码管理的分支名改为下拉选择器：列出本地分支、标记当前分支，并可直接输入名称创建并切换新分支；已在其他 worktree 检出的分支会标记并禁用切换，避免 `git switch` 报错；切换失败（例如本地修改会被覆盖）会弹出居中的错误对话框，而不是在侧栏显示内联红字。右侧「全部关闭」按钮已移除，改为标签右键菜单（关闭、关闭其他、关闭右侧标签页、关闭已保存、全部关闭）；Monaco 编辑器显式预加载中文语言包，右键菜单等内置文案使用中文（`zh-cn`）；打开文件时不再默认高亮第一行，只有点击编辑器后才显示当前行高亮。深色主题下隐藏 DSH 对话栏时，工作台会继续保持 DSH 标题栏的深色，不再出现顶部变白；工作台底部状态栏改为 VS Code 风格的深/浅色底，不再固定为蓝色。终端面板可向下拖动隐藏；隐藏后从编辑器底部边缘向上拖动可重新拉出终端。资源管理器和标签栏改用 `vscode-icons` 彩色文件/文件夹图标包，图标由新增的 `/dsh-vscode/file-icons` 路由按需提供。DSH 对话栏在固定深色模式下也使用同一套底色。工作台入口移入 DSH 侧栏的面板列表（与「插件」「自动化任务」等并列），不再使用右下角悬浮按钮；DSH 对话栏的开关移到活动栏的鲸鱼图标，可随时打开或关闭。

## 0.1.14

修复 Windows Desktop 的顶部叠字：DSH 0.2 的 Windows 自定义标题栏会在窗口顶部预留 40px，并绘制「应用」「编辑」菜单；工作台现在识别 `data-windows-titlebar`，从标题栏下沿开始布局，不再与「源代码管理」等侧栏标题重叠，同时保留标题栏的拖动区域。开发与测试基线同步升级到 Harness `0.2.2-rc.1` / Cordis `4.1.0`，并在 `0.2.1-rc.5` / Cordis `4.0.5` 上保留兼容范围。

同时处理大仓库与多标签场景：文件监听默认跳过 `vendor`、`third_party`/`third_part`、`build`、`dist`、`out`、`target`、`.venv`、`__pycache__` 等大目录，并允许在工作台设置里追加排除项；监听资源耗尽时只停用自动刷新，不再让 DSH 因 inotify 上限崩溃。标签栏改为单行省略并隐藏原生滚动条，关闭全部按钮固定右侧，切换标签时自动滚入可视区域。底部状态栏默认隐藏，可在设置中重新开启。

## 0.1.12

集中修复可靠性与 macOS 使用问题：保留并恢复工作区草稿，加强并发保存和文件操作；补齐可拖动标题栏与窗口留白，修正活动工作台的 DSH 原生侧栏遮挡；WebSocket 地址跟随 DSH transport，终端启动时自动修复 `spawn-helper` 执行位。PDF、DOCX、图片和 Markdown 预览已在 DSH Desktop 中实际验证。

## 0.1.11

将 DSH 开发依赖与 peerDependencies 同步至 `0.2.1-rc.5`，Cordis 保持 `4.0.5`，并显式声明 `engines.dsh`；同时显式声明 `0.2.2-rc.1` 的预发布依赖范围。安装版本闸门使用官方 `evaluatePluginCompatibility()` 验证，无需版本豁免。

两套依赖环境均通过类型检查、52 项测试及构建，覆盖官方版本闸门、真实 Harness cookie 认证与会话目录切换回归；尚未完成完整 DSH 页面端到端验证。next 渠道需 Node.js ≥24.9。
