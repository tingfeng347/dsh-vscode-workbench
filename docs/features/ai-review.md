# AI 改动审阅

AI 改动审阅默认关闭。设置提供与 Trae 一致的三种模式：

- **审阅全部改动**：保留每一轮尚未处理的 AI 差异，直到逐个处理。
- **审阅最新改动**：新任务开始产生差异时，自动保留上一任务的待审阅结果。
- **无需审阅**：自动接受全部改动，不轮询或展示审阅入口。

审阅开启后，工作台按 Trae 的三层粒度处理 DSH 文件工具已经写入磁盘的改动：

- 绿色行表示新增或修改后的内容。
- 红色删除块显示被替换的旧内容。
- 单处改动在右上角显示 `^Y` 和 `^N`；Windows/Linux 快捷键为 `Alt+Y` 和 `Alt+N`。
- 编辑器顶部提示条显示当前文件的“接受”和“拒绝”；快捷键为 `Ctrl+Enter` 和 `Ctrl+Backspace`。
- DSH 输入框上方显示待审阅文件列表和“全部接受”“全部拒绝”；点击文件名会在工作台打开对应位置。
- 标签会显示待审阅块数。只有确实无法安全定位的差异才显示错误状态。
- 设置项位于“默认浏览器”之后。“自动跟随 AI 修改”仅在审阅开启时显示。

## 数据来源与边界

宿主从当前 DSH 会话中成功完成的 `edit`、`write` 和 `str_replace_editor` 文件操作提取差异。优先使用工具结果里的已应用差异元数据；只有参数足以安全还原时才采纳没有结果差异的 `str_replace_editor` 操作。

终端命令、格式化器、编辑器手工保存以及其他外部程序对文件的修改不属于 AI 工具差异。无法唯一匹配完整行、CRLF、二进制、超过 5 MiB、运行中的 AI 回合和同文件任一块冲突都会阻止自动撤销。工作台不会覆盖无法证明属于该 AI 块的用户修改。

“接受”只在客户端记录该块已处理，不执行 Git 暂存或提交。“拒绝”通过宿主原子保存文件；同文件多块在一次 revision 校验、逆序还原和一次写入中完成，任何一块冲突时整文件不写。AI 新建文件后再由同一审阅链继续修改时，文件级拒绝会先反向还原所有后续 AI 块，确认内容回到创建基线后再删除整个新文件。若发现无法归因的用户修改，则保留文件并报告真实冲突。

## API

所有接口使用现有认证的 `POST /dsh-vscode/api/<method>`，请求包含当前 `sessionId`，响应沿用 `{ ok, value }` 或 `{ ok: false, error }`。

- `review.feed({ sessionId, from? })`
  - `from` 是包含式事件水位；省略时从当前会话末尾开始，供首次开启时建立水位。
  - 返回 `{ cursor, changes, busy }`。
  - `changes` 项包含 `id`、`seq`、`turn`、`path`、`before`、`after`、`created`、`kind`、`locator`、`hunk`。`path` 已规范化并限制在当前工作区内；`turn` 用于“审阅最新改动”模式。
- `review.inspect({ sessionId, path, ids })`
  - 返回 `{ path, revision, content, changes: [{ id, conflict? }] }`。
  - `revision` 绑定当前磁盘内容，客户端撤销时必须原样带回。
- `review.reject({ sessionId, path, ids, revision })`
  - 返回 `{ path, deleted, rejectedIds, document? }`。
  - `deleted` 为真表示安全删除了 AI 创建的文件；后续 AI 块已先反向还原到创建基线。

客户端在审阅模式开启且工作台可见时每 800ms 增量拉取一次。会话级起点和已保留块 ID 保存在 `localStorage`，刷新后恢复。切到“无需审阅”会停止轮询并清除旧审阅水位，保证之后重新开启审阅时只显示新改动。

## 跟随与跳转

收到新块后，工作台等待用户连续空闲 1.5 秒再定位原文件。键盘输入、滚轮、指针和触摸操作会重新开始等待。跟随只滚动并选中差异位置，不会把焦点从正在操作的输入区抢回 Monaco。跟随开关在设置中控制。

DSH 右侧生成的 `dsh-resource://file/session/<sessionId>/<path>` 链接在工作台可见且会话匹配时，会转为工作台内打开事件；地址携带的 `line` 参数会传给 Monaco。其他会话、非法地址或工作台隐藏时仍走 DSH 原行为。

工作台可见时，DSH 对话末尾的“已编辑 N 个文件 / 本轮改动”卡片会打开工作台原文件：点击具体文件行会定位到对应路径，点击卡片标题则打开列表中的第一个文件。工作台隐藏时卡片继续使用 DSH 官方预览；“展开全部”始终由 DSH 处理，不改变官方列表行为。

## 关键实现

- `src/review.ts`：会话事件提取、工作区路径校验、差异定位、批量还原、revision 冲突和新文件保护。
- `src/client/aiReview.ts`：增量轮询、持久化水位、保留记录、检查与撤销请求。
- `src/client/MonacoEditor.tsx`：绿色行装饰、红色删除 view zone、浮动 `^Y/^N` 块级操作以及不抢焦点的定位。
- `src/client/Workbench.tsx`：标签计数、编辑器文件级提示条、全部接受/拒绝、空闲跟随、拒绝后的刷新和 DSH 文件打开事件。
- `src/client/DshConversationPanel.tsx`：把全部改动入口挂到 DSH 输入框上方，同时保留官方对话组件。
- `src/client/generatedFileLinks.ts`：DSH 生成文件地址拦截与本会话限制。
