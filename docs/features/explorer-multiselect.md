# 资源管理器多选

资源管理器支持按当前展开顺序选择可见文件和文件夹：

- 普通点击保持原有行为：文件打开，文件夹切换展开状态。
- `Ctrl/⌘+点击` 切换一个项目的选中状态，不会打开或展开该项目。
- `Shift+点击` 从上次选择的锚点选中连续可见范围；同时按住 `Ctrl/⌘` 会把范围加入已有选择。
- `Ctrl/⌘+A` 选择当前可见的全部项目，`Shift+↑/↓` 扩展或收缩连续选择，`Home/End` 跳到首尾项目。
- `Ctrl/⌘+C` 或右键菜单复制选中项目的相对/绝对路径，每行一个。
- `Delete` 或 `Backspace` 打开批量删除确认；若同时选中文件夹及其子项，只删除最外层文件夹一次。
- `Esc` 清空选择或关闭删除确认。工作区切换时选择自动清空。

删除按项目逐个调用现有的 `fs.delete`，不是文件系统级原子事务。部分项目失败时，成功项目保持删除状态，确认框关闭后显示失败列表并把失败项留在选择集中。
