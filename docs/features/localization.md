# 工作台中文补全

## 范围与行为

- 中文包加载完成后、Monaco 主模块加载前，补齐 Monaco 0.52.2 中文包中的 31 个空翻译；保留已有翻译及格式占位符。
- 普通编辑器及差异编辑器补全 5 个硬编码的内联编辑命令名称，只调整显示标签，保留原命令对象、英文搜索别名、启用条件、快捷键和执行逻辑。
- 设置入口显示「工作台」，分支占用标记显示「工作树」，编辑器加载错误、上传失败及模型设置提示使用中文。
- 品牌名称、编程语言、快捷键名称和外部工具返回的原始技术详情继续保留原文。
