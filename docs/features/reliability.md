# 数据保护与故障恢复

本文汇总工作台在文件编辑、草稿恢复、文件监听和远程操作中的数据保护规则。

## 文件与草稿

- 编辑草稿按 Session 和工作区隔离保存。刷新或切换会话后恢复时，会核对磁盘版本，避免覆盖外部修改。
- 保存前检查文件版本；同一路径的并发保存串行处理，并在写入前再次校验。替换文件时尽量保留原权限和工作区内符号链接。
- 文件操作拒绝目录穿越、逃出工作区的符号链接，以及删除解析后等于工作区根目录的路径。
- 二进制文件、非 UTF-8 内容和超出支持大小的文件不会作为普通文本写回。

## 文件监听与加载

- 文件变化仅刷新相关路径。干净文件可同步磁盘更新；有未保存草稿时保留编辑内容并提示外部变化。
- 恢复布局时优先读取可见编辑组的活动文件；隐藏编辑器不触发无用加载。
- 监听连接或按需加载失败后可重试；重新显示工作台时补读隐藏期间的文件变化。

## Git、搜索与 SSH

- Git 写操作会检查状态或版本，过期操作会报告冲突，而不是静默覆盖。
- 工作区搜索限制结果数量和输出规模，并标记结果是否被截断。
- SSH 路径通过远端真实路径校验，拒绝越出已选工作区的操作；远程搜索和保存遵循与本地类似的路径及版本检查。
- 批量删除按项目执行，不是文件系统级事务；部分失败时保留失败项并给出结果。

## 验证范围

自动化测试覆盖临时文件、Git 仓库、工作区组件和模拟 SSH 边界。CI 的类型检查、测试与构建验证代码和产物；模拟 SSH 测试不等同于真实网络或任意远端主机的端到端验收。
