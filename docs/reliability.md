## 性能与数据完整性修复（2026-11-25）

用户在 `main@88eccb0` 审查后要求“优化一下”。本次先修复审查确认的九项问题：恢复布局仅加载各分栏活动文件；文件监听就绪不等待固定超时；切换工作区前保全待写草稿；本地读取失败提供重试；远程 Git 按字面文件名操作；拒绝有损 UTF-8 编辑和替换；远程搜索拒绝失效工作区；远程保存保留内部符号链接；搜索达到全局结果上限后停止收集输出。

验证入口沿用工作台组件及公开宿主方法：组件测试检查恢复请求、草稿恢复和读取重试；真实 chokidar 测试检查文件就绪耗时及随后写入通知；SSH 测试通过临时 OpenSSH 替身执行实际远端脚本，检查 Git 影响文件、原始字节、链接身份、路径边界和搜索结果上限。后者不等同真实 SSH 网络端到端验证。

干净 PR 工作区的自动化验收已完成：Vitest 为 85 个文件通过、2 个文件跳过，567 项测试通过、4 项跳过；TypeScript 类型检查、完整构建和 `git diff --check` 通过。工作台、文件监听、SSH 文件操作三个提交还分别通过对应回归。任务开始前已有的 `tests/ssh.spec.ts` 修改和 `src/archive.ts` 保留在原工作区，不纳入本次 PR；原工作区的 568 项通过结果包含其中一项归档测试。
