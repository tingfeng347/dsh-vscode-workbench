# 工作台可靠性修复

用户要求：修复项目分析中发现的问题，然后提交并推送。

本次行为范围：

- 隐藏工作台不丢失草稿；刷新和切换会话后可恢复草稿，恢复时仍校验磁盘版本。
- 保存响应保留请求期间的新编辑；同一文件的并发保存必须重新检查版本。
- 保存保留文件权限与内部符号链接；不允许删除解析后的工作区根目录。
- Git 状态显示合并冲突；正确处理重命名记录。
- 文件通知只影响对应标签；干净文件自动刷新，脏文件保留草稿并提示外部变化。

验证入口：`saveDocument` / `deleteEntry` / `gitStatus`（真实临时文件及 Git 仓库），以及工作台组件交互（模拟网络与编辑器渲染边界）。本地类型检查、完整测试及构建；组件测试不等同完整 DSH 页面端到端验证。

范围外：新增冲突比较界面、文件操作联动标签和终端自动重连等功能扩展。

## 验收结果

已完成上述修复，并通过 `pnpm test`（15 个测试文件、69 项测试）、`pnpm typecheck`、`pnpm build` 和 `git diff --check`。新增 17 项测试覆盖根目录删除别名、权限和符号链接、并发保存、Git 冲突与重命名、草稿恢复、保存与读取竞态、外部变更和隐藏布局恢复。

草稿按会话与工作区保存在当前浏览器 localStorage；存储失败会显示错误。保存队列按规范化文件路径在当前宿主进程内串行化，临时文件替换前再次校验版本；不声称与任意外部进程之间具有文件系统级比较并交换保证。权限位测试和文件符号链接测试在 Windows 跳过。

验证限制：browser-use CLI 未安装，应用内浏览器服务不可用，因此未完成真实 Monaco 浏览器交互或完整 DSH 页面端到端验证。组件测试替换了 Monaco/DSH 渲染和网络边界；文件及 Git 测试使用真实临时目录和仓库。代码规范与需求对照采用本次工作区自审，未进行独立代理审查。
